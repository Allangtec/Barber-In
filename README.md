# 💈 Barber In

## Sistema de agendamento online para barbearias

O **Barber In** é uma solução desenvolvida para facilitar o agendamento de serviços em barbearias, permitindo que clientes escolham serviços, horários e realizem seus agendamentos de forma online.

## 🚀 Sobre o projeto

O sistema foi desenvolvido utilizando uma arquitetura baseada em:

- 🌐 Aplicação web
- 🤖 Automação com n8n
- 🔗 Integrações via API
- 🗄️ Banco de dados
- ☁️ Hospedagem em servidor

## ✨ Funcionalidades

- 📅 Agendamento online
- 💈 Cadastro de serviços
- 👤 Gerenciamento de clientes
- ⏰ Controle de horários
- 🔄 Automações
- 🔗 Integrações entre sistemas
